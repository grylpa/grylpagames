# Cardboard texture

`cardboard_color.jpg`, `cardboard_normal.jpg` (OpenGL convention) and `cardboard_roughness.jpg` are
**Cardboard 004** from ambientCG (https://ambientcg.com/view?id=Cardboard004), downscaled from the
1K set to 512 px. ambientCG releases its assets under **CC0 1.0** (public domain): no attribution is
required, and it is given here only so the source can be found again.

Used by `scripts/parcel_art.gd` (the sorting games' 3-D parcels).
